# Public journey contract

Use the product idea's domain language and cover every baseline journey:

1. Start at `http://localhost:3000` without errors.
2. Add a complete record and show it in the list.
3. Edit and delete an existing record.
4. Narrow the list using the idea's meaningful category or state.
5. Show the requested derived value.
6. Preserve required data across a browser refresh.
7. Record the decision made for the idea's ambiguity in `assumptions`.

If the idea genuinely makes a journey inapplicable, implement the closest useful equivalent and record the decision. Treat journey coverage as fixed; minimize implementation complexity within that coverage.
